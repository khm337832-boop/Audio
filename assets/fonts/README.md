# Fonts

`thumbnail_service` က ဒီ folder ထဲက font တွေကို အရင် ရှာတယ်။ မြန်မာစာသား ထပ်ရေးတဲ့အခါ
မြန်မာ glyph ပါတဲ့ font မရှိရင် စာလုံးတွေ လေပ်နေနိုင်တယ်။

| ဖိုင် | အသုံး | လိုင်စင် |
|------|-------|--------|
| `Padauk-Bold.ttf`, `Padauk-Regular.ttf` | မြန်မာစာသား (thumbnail) | SIL Open Font License 1.1 — `OFL.txt` |

Source: <https://github.com/google/fonts/tree/main/ofl/padauk>

တခြား font သုံးချင်ရင် ဖိုင်ကို ဒီ folder ထဲ ထည့်ပြီး `.env` မှာ
`THUMBNAIL_FONT=assets/fonts/YourFont.ttf` လို့ သတ်မှတ်နိုင်တယ်။
